## 🧭 درباره پروژه

**سفیرسازان** یک قالب دو-صفحه‌ای کامل برای کسب‌وکارهای مشاور املاک است:

1. **صفحه اصلی** (`index.html`) — معرفی خدمات، نمایش املاک ویژه، فرآیند همکاری، نظرات مشتریان و سوالات متداول
2. **صفحه همه آگهی‌ها** (`listings.html`) — جست‌وجو و فیلتر پیشرفته میان تمام آگهی‌ها، دقیقاً با تجربه‌ای شبیه دیوار و شیپور اما با ظاهری اختصاصی و هماهنگ با هویت بصری سفیرسازان

هر دو صفحه با طراحی راست‌به‌چپ (RTL) و تایپوگرافی فارسی، و از یک فایل CSS پایه و یک زبان طراحی مشترک استفاده می‌کنند — یعنی رنگ‌ها، فونت، فاصله‌گذاری و کامپوننت‌ها در سراسر سایت کاملاً یکدست هستند.

نقطه تمایز اصلی این پروژه نسبت به قالب‌های مشابه:

- **بدون فریم‌ورک، بدون build**: فقط HTML + CSS + JavaScript خالص. کافیست فایل‌ها را آپلود کنید.
- **بدون وابستگی به سرور شخص ثالث**: فونت فارسی (Vazirmatn) به‌صورت لوکال سرو می‌شود، تصاویر SVG برداری‌اند — یعنی هیچ بخشی از سایت به یک CDN یا API خارجی وابسته نیست و هرگز به‌خاطر قطعی یک سرویس بیرونی از کار نمی‌افتد.
- **آماده تولید (Production-ready)**: سئوی کامل (Open Graph، JSON-LD، sitemap)، دسترس‌پذیری استاندارد (WCAG-friendly)، و آزمایش‌شده روی ۱۶+ سایز صفحه مختلف.

## 🔎 صفحه همه آگهی‌ها (جست‌وجو و فیلتر)

`listings.html` یک صفحه جست‌وجوی کامل و مستقل است که تمام ۳۰ آگهی نمونه را با قابلیت‌های زیر نمایش می‌دهد:

<table>
<tr>
<td valign="top" width="50%">

**جست‌وجو و فیلتر**
- جست‌وجوی زنده بر اساس عنوان، منطقه یا شهر
- تب‌های نوع معامله (خرید، اجاره، رهن کامل)
- فیلتر نوع ملک (ویلا، آپارتمان، پنت‌هاوس، زمین، تجاری، اداری) با شمارنده تعداد
- بازه قیمت و بازه متراژ (حداقل/حداکثر)
- فیلتر تعداد اتاق خواب (چیپ‌های سریع)
- فیلتر امکانات (پارکینگ، آسانسور، استخر، روف‌گاردن و...)
- فیلتر چندگزینه‌ای موقعیت مکانی (۱۸ منطقه لاهیجان)
- چیپ‌های فیلتر فعال با امکان حذف تکی یا پاک‌کردن همه

</td>
<td valign="top" width="50%">

**نمایش نتایج و تجربه کاربری**
- مرتب‌سازی: جدیدترین، ارزان‌ترین، گران‌ترین، بیشترین متراژ
- نمایش شبکه‌ای (Grid) یا لیستی (List) با یک کلیک
- صفحه‌بندی هوشمند (Pagination) با شماره صفحه
- **مودال جزئیات ملک**: کلیک روی هر آگهی، پنجره‌ای با عکس بزرگ، مشخصات کامل، توضیحات، امکانات و دکمه تماس با مشاور باز می‌کند
- حالت خالی (Empty State) با دکمه پاک‌کردن فیلترها
- کشوی فیلتر تمام‌صفحه در موبایل (مثل اپلیکیشن‌های دیوار/شیپور)
- **URL هوشمند**: فیلترهای فعال در آدرس صفحه ذخیره می‌شوند، یعنی می‌توانید نتیجه فیلترشده را کپی و برای کسی ارسال کنید

داده نمونه در فایل جداگانه `js/listings-data.js` نگه‌داری می‌شود — جایگزین‌کردن آن با پاسخ یک API واقعی (مثلاً از یک بک‌اند یا دیتابیس) کافی است تا کل صفحه بدون هیچ تغییر دیگری با داده واقعی کار کند.

## 🚀 پیش‌نمایش سریع

برای مشاهده لوکال، فقط `index.html` را در مرورگر باز کنید — نیازی به نصب چیزی نیست. برای تجربه کامل (بارگذاری صحیح فونت‌ها با CORS)، پیشنهاد می‌شود از یک سرور محلی ساده استفاده کنید:

```bash
# با پایتون (از قبل روی اکثر سیستم‌ها نصب است)
python3 -m http.server 8080

# یا با Node.js
npx serve .

# سپس در مرورگر باز کنید:
# http://localhost:8080
```

## ⚡ شروع سریع

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/<your-username>/safirsazan.git
cd safirsazan

# ۲. اجرای سرور محلی
python3 -m http.server 8080

# ۳. باز کردن در مرورگر
open http://localhost:8080   # مک
# یا صرفاً به آدرس بالا در مرورگر خود بروید
```

هیچ `npm install`، هیچ فرآیند build و هیچ فایل پیکربندی‌ای در کار نیست — این یک پروژه کاملاً استاتیک است.

## 🌐 استقرار روی هاست (Deploy)

چون این پروژه کاملاً استاتیک است (بدون بک‌اند یا دیتابیس)، روی هر سرویسی قابل میزبانی است:

| روش | مراحل |
|---|---|
| **هاست اشتراکی / cPanel** | تمام فایل‌ها را داخل `public_html` آپلود کنید (FTP یا File Manager) |
| **GitHub Pages** | از تنظیمات ریپو → Pages → شاخه `main` را به‌عنوان منبع انتخاب کنید |
| **Netlify / Vercel / Cloudflare Pages** | ریپو را متصل کنید؛ چون build نیاز نیست، Publish directory را روی ریشه (`/`) بگذارید |

## 🎨 سفارشی‌سازی

### رنگ‌ها و توکن‌های طراحی

تمام رنگ‌ها، شعاع گوشه‌ها و سایه‌ها به‌صورت متغیرهای CSS در ابتدای `css/style.css` تعریف شده‌اند — کافیست این بخش را ویرایش کنید تا کل سایت به‌روزرسانی شود:

```css
:root{
  --gold:#c9a25c;        /* رنگ طلایی اصلی برند */
  --gold-dark:#a9803f;   /* طلایی تیره (هاور و تاکید) */
  --dark:#191a1e;        /* رنگ تیره (هدر، فوتر، دکمه‌ها) */
  --cream-1:#fdfbf6;     /* پس‌زمینه روشن اصلی */
  --text:#20222a;        /* رنگ متن اصلی */
  --container:1220px;    /* حداکثر عرض محتوا */
  --font:'Vazirmatn', 'Tahoma', sans-serif;
}
```

### متن‌ها و محتوا

تمام متن‌های سایت مستقیماً در `index.html` نوشته شده‌اند (بدون سیستم i18n یا CMS) — با جست‌وجوی متن مورد نظر در فایل، آن را ویرایش کنید.

### فرم جستجو و اتصال به داده واقعی

- فرم جستجوی صفحه اصلی (`#searchForm` در `index.html`) مقادیر انتخاب‌شده (موقعیت، متراژ، قیمت، نوع ملک، نوع معامله) را به‌صورت پارامترهای URL به `listings.html` می‌فرستد؛ یعنی فیلترهای صفحه آگهی‌ها از همان لحظه ورود، از قبل با انتخاب کاربر تنظیم شده‌اند.
- موتور جست‌وجو/فیلتر واقعی در `listings.html` پیاده‌سازی شده و از آرایه `PROPERTY_LISTINGS` در `js/listings-data.js` می‌خواند. برای اتصال به یک بک‌اند واقعی، کافیست همین فایل را با یک فراخوانی `fetch()` به API خودتان جایگزین کنید — بقیه صفحه (فیلتر، مرتب‌سازی، صفحه‌بندی، مودال جزئیات) بدون تغییر کار خواهد کرد، چون همه‌چیز بر پایه همین ساختار داده‌ای عمل می‌کند.

## 🖼 جایگزینی عکس‌های واقعی ملک

**صفحه اصلی (`index.html`):** عکس‌های آگهی‌های ویژه از قبل با نام‌های واقعی (مثل `Aparteman Shams karegar 1.jpg`) در `index.html` لینک شده‌اند. فعلاً به‌جای این عکس‌ها یک تصویر نمونه هشداردار قرار دارد — فهرست کامل و دقیق در بخش [«قبل از هر کاری»](#️-قبل-از-هر-کاری-عکسهای-نمونه-را-جایگزین-کنید) بالای همین فایل آمده. کافیست فایل جدید را با همان نام دقیق در `assets/img/` یا `assets/img/advertisements/` جایگزین کنید — نیازی به تغییر کد نیست.

**صفحه آگهی‌ها (`listings.html`):** ۳۰ آگهی نمونه در `js/listings-data.js` هنوز از تصاویر برداری SVG (`assets/img/property-1.svg` … `property-12.svg`) استفاده می‌کنند، چون این‌ها داده آزمایشی هستند و قرار است در نهایت با API واقعی جایگزین شوند. برای جایگزینی هرکدام با عکس واقعی:

1. عکس را در پوشه `assets/img/advertisements/` قرار دهید (پیشنهاد: نسبت ۴:۳، حداکثر عرض ۸۰۰px، فرمت `webp` یا `jpg` فشرده زیر ۲۰۰ کیلوبایت)
2. مقدار `"image"` مربوط به همان آگهی را در `js/listings-data.js` به‌روزرسانی کنید:

```js
// قبل
"image": "assets/img/property-1.svg",

// بعد
"image": "assets/img/advertisements/my-real-photo.jpg",
```

## 📱 ریسپانسیو و بریک‌پوینت‌ها

طراحی روی ۱۶ سایز صفحه (از ۳۲۰ تا ۱۴۴۰ پیکسل) تست شده است — از کوچک‌ترین گوشی‌های موجود تا دسکتاپ‌های بزرگ، در هر دو صفحه اصلی و آگهی‌ها:

| بریک‌پوینت | دستگاه هدف |
|---|---|
| `≤ 400px` | گوشی‌های خیلی کوچک (iPhone SE و مشابه) |
| `≤ 480px` | گوشی‌های استاندارد |
| `≤ 680px` | گوشی‌های بزرگ / فبلت |
| `≤ 820px` | تبلت پرتره (iPad mini/Air) |
| `≤ 992px` | تبلت لندسکیپ |
| `≤ 1180px` | لپ‌تاپ‌های کوچک |
| `> 1180px` | دسکتاپ استاندارد |

نکات فنی رعایت‌شده برای تجربه موبایل بدون نقص:

- بدون اسکرول افقی در هیچ‌کدام از بریک‌پوینت‌ها
- تمام تارگت‌های لمسی حداقل ۳۲×۳۲ پیکسل
- فونت فیلدهای فرم حداقل ۱۶px (برای جلوگیری از زوم خودکار سافاری iOS)
- کروسل با `scroll-snap` و پشتیبانی swipe؛ فلش‌های ناوبری در موبایل مخفی می‌شوند (رفتار native جایگزین می‌شود)

## ♿ دسترس‌پذیری (Accessibility)

- ساختار معنایی HTML5 (`<header>`, `<main>`, `<nav>`, `<footer>`)
- لینک «رفتن به محتوای اصلی» برای کاربران کیبورد/صفحه‌خوان
- تمام آیکون‌های تزئینی با `aria-hidden="true"` از صفحه‌خوان مخفی شده‌اند
- آکاردئون سوالات متداول با تگ بومی `<details>/<summary>` — کاملاً در دسترس و حتی بدون جاوااسکریپت هم کار می‌کند
- تمام انیمیشن‌ها به `prefers-reduced-motion: reduce` احترام می‌گذارند

## 🔍 سئو و متادیتا

- متا تگ‌های کامل `description`، `Open Graph` و `Twitter Card`

- برچسب `canonical` (پیش از انتشار، دامنه واقعی را جایگزین کنید)

## ⚙️ عملکرد (Performance)

- بدون هیچ کتابخانه یا فریم‌ورک خارجی — فقط HTML/CSS/JS خام
- فونت با `font-display: swap` و `preload` برای جلوگیری از پرش محتوا (CLS)
- تمام تصاویر SVG (چند کیلوبایت در مقابل چند صد کیلوبایت عکس معمولی)
- بارگذاری تنبل (`loading="lazy"`) برای تصاویر ملک‌های زیر صفحه اول
